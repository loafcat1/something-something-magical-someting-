PROJECT ECHO — a tiny mystery for a friend

FILES: index.html, field-notes.html, smile.html, pocket.html, final.html, style.css.

TEST LOCALLY: Open index.html in a browser. Answer checks link the puzzle pages.

FREE HOSTING WITH GITHUB PAGES:
1. Create a GitHub repository named project-echo.
2. Upload all files in this folder into the repository root.
3. Open Settings > Pages.
4. Choose deploy from a branch, select main and /(root), then save.
5. Wait for the published URL and test it in a private/incognito window.
6. Send only the homepage URL to your friend.

This is a playful puzzle, not secure access control; public repository source is visible. Don't include passwords or private information.

GAME MASTER ANSWERS:
1. Base64 L2ZpZWxkLW5vdGVzLmh0bWw= -> /field-notes.html
2. First letters of lines -> SMILE -> /smile.html
3. Shift letters backward by one: UIF GJOBM OPUF JT JO UIF QPDLFU -> THE FINAL NOTE IS IN THE POCKET -> /pocket.html
4. A1Z26 25-15-21 -> YOU -> /final.html

HINTS:
1. Decode Base64.
2. Read the first letter of each line.
3. Shift each letter one place backward.
4. A=1, B=2, C=3.

Personalize the final note if you want, keeping it kind and low-pressure.
